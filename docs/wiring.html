🌊 Tide Gauge

Standalone ESP32 · Center-zero galvanometer · NOAA Station 9444900 Port Townsend, WA
Repurposed "Yards Per Second" gauge — ±0.5 mA end scale · MCP6002 op-amp buffered drive

Schematic

GPIO26 → U1A → gauge +

GPIO26 (DAC2) drives the U1A op-amp input. The unity-gain buffer presents ~1TΩ impedance to the DAC (no loading) and drives R3 with ~100Ω source impedance.

At DAC 128 the output is 1.65 V — equal to the reference side — so no current flows and the needle sits at center.

GPIO25 → U1B → gauge −

GPIO25 (DAC1) mirrors GPIO26 inverted in firmware (dacVal = 255 − GPIO26). The U1B buffer drives R4 with low impedance.

Push-pull: when GPIO26 rises, GPIO25 falls by the same amount, doubling the differential voltage across the gauge.

Current Calculation

Op-amp output impedance ~100Ω (vs ESP32 DAC's ~3–4 kΩ). At full swing: 3.1 V ÷ (3000 + 49 + 3000) ≈ 510 µA — matching the 0.5 mA FSD spec.

R3 and R4 are set with 10 kΩ trimpots (~3 kΩ each).

Calibration

If the needle rests off-center with no tide data, adjust DAC_CENTER (default 128) in src/main.cpp up or down by a few counts and reflash.

The reference pin (DAC_REF_PIN) always tracks 255 − DAC_CENTER. Also set trimpots R3 and R4 to ~3 kΩ each with a multimeter before connecting the gauge.

Tide Scale

NOAA station 9444900 Port Townsend: MSL = 8.35 ft above MLLW.

Gauge maps ±8 ft from MSL to full deflection. Adjust TIDE_SCALE_FT in firmware if the local tidal range is smaller.

DAC Note

ESP32 DAC outputs are GPIO25 (DAC1) and GPIO26 (DAC2). Both are 8-bit (0–255).

MCP6002 power: VCC → 3.3 V, GND → GND. Bypass with 100 nF ceramic cap across VCC–GND close to the chip.

Do not use GPIO26 for anything else while the gauge is connected. ADC reads on this pin will be inaccurate.

How the Needle Moves

Needle Right — Tide Above MSL

DAC > 128 → GPIO26 rises above 1.65 V → U1A output rises, U1B output falls → current flows into gauge+, through the coil, out gauge− → needle deflects right.

Needle Center — Tide at MSL

DAC = 128 → GPIO26 = 1.65 V = GPIO25 reference voltage → zero differential across the coil → no current flows → needle rests at center zero.

Needle Left — Tide Below MSL

DAC < 128 → GPIO26 drops below 1.65 V, GPIO25 rises → U1B output is now higher than U1A → current flows into gauge−, through the coil in reverse, out gauge+ → needle deflects left.

Why This Works at Full Scale

The MCP6002 op-amp buffers are the key: without them the ESP32 DAC's ~3–4 kΩ output impedance adds to R3/R4 and limits peak current to ~55% of FSD. With the buffers (~100Ω output impedance each), the full 3.1 V differential is available across the gauge circuit, reaching the rated ±0.5 mA at full deflection.

Build Steps

1
Wire MCP6002 power. Connect MCP6002 VCC (pin 6) → ESP32 3.3 V, GND (pin 3) → GND. Bypass with a 100 nF ceramic capacitor across VCC–GND placed close to the chip.
2
Wire op-amp buffers. Connect GPIO26 → U1A (+in, pin 5). Connect GPIO25 → U1B (+in, pin 3). Tie each (−in) to its own output: U1A (−in pin 6 → out pin 1), U1B (−in pin 2 → out pin 7). Each op-amp is now a unity-gain voltage follower.
3
Series resistors. Connect U1A output → R3 (~3 kΩ) → gauge (+) terminal. Connect U1B output → R4 (~3 kΩ) → gauge (−) terminal. Set R3 and R4 with a multimeter to ~3 kΩ each before connecting the gauge.
4
Connect gauge. GPIO26 side → gauge (+), GPIO25 side → gauge (−). Confirm polarity on the test page (/test) by setting DAC to 255 and verifying the needle deflects right (positive). Swap leads if reversed.
5
Flash firmware. Run ~/.platformio/penv/bin/pio run -t upload (pio is not in PATH). On first boot the ESP32 opens a WiFi AP named TideGauge — connect and enter your WiFi credentials in the captive portal.
6
Calibrate. Open the /test page. Set slider to 255: needle should reach full-scale right. Set to 0: full-scale left. Adjust trimpots if not reaching full deflection. Set to 128: needle should center. Adjust DAC_CENTER in firmware if off-center and reflash.
7
Boot sweep. After reset, the needle sweeps left → right → center, confirming gauge drive is working before tide data is fetched.
8
Verify tide. Open http://<device-ip>/ in a browser. Compare the displayed tide level to NOAA station 9444900. The needle should center when tide equals MSL (8.35 ft above MLLW at Port Townsend).

Firmware Overview

NOAA Tide API

Station 9444900 Port Townsend, WA. Polls water level every 6 min and hi/lo predictions every cycle. Uses MLLW datum, English units.

Weather

Open-Meteo API — no key required. Fetches current temperature, wind, and WMO weather code every 15 min. Coordinates: 48.115, −122.760 (Freeland WA).

Web Page

Embedded dark-theme HTML served from http://<ip>/. Auto-refreshes every 30 s. Includes a tide bar, next hi/lo, weather panel, WiFi info, and a Reset WiFi button.

WiFiManager

AP name: TideGauge. Portal times out after 3 minutes and reboots. Saved credentials survive power cycles. Reset button at /reset clears them.

// ── Pin / scale ──────────────────────────────
#define DAC_PIN       26    // GPIO26 (DAC2) → MCP6002 U1A → R3 → gauge (+)
#define DAC_REF_PIN   25    // GPIO25 (DAC1) → MCP6002 U1B → R4 → gauge (−)
#define DAC_CENTER    128   // 1.65 V mid-point → needle at center
#define DAC_POS       255   // full positive — op-amp buffers enable full rail
#define DAC_NEG         0   // full negative
#define TIDE_SCALE_FT 8.0f  // ±8 ft from MSL = full deflection
#define NOAA_MSL_FT   8.35f // Port Townsend MSL above MLLW

// ── Poll intervals ───────────────────────────
#define TIDE_INTERVAL_MS    360000UL  //  6 min
#define WEATHER_INTERVAL_MS 900000UL  // 15 min
#define DISPLAY_INTERVAL_MS   5000UL  //  5 s needle update

// ── Tide → DAC mapping ───────────────────────
uint8_t tideToDAC(float deltaMSL) {
  float clamped    = constrain(deltaMSL, -TIDE_SCALE_FT, TIDE_SCALE_FT);
  float normalized = clamped / TIDE_SCALE_FT; // −1.0 to +1.0
  int   dac        = DAC_CENTER + (int)(normalized * (DAC_POS - DAC_CENTER));
  return (uint8_t)constrain(dac, DAC_NEG, DAC_POS);
}
